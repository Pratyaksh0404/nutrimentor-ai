# NutriMentor AI

NutriMentor AI is an explainable nutrition and diet planning platform focused on fruits and vegetables.

The goal of this project is to help users understand nutrition scientifically, identify nutrient deficiencies, and build balanced diets using clean design and intelligent recommendations.

## Planned Features
- Fruits & vegetables catalog
- Seasonal availability insights
- Vitamin & mineral breakdown
- RDA-based nutrient deficiency analysis
- Diet plan builder with explanations
- ML-powered food similarity search
- Health mentor chatbot for nutrition guidance

## Tech Stack
- Frontend: React, Tailwind CSS
- Backend: FastAPI
- Database: SQLite (development)
- ML: PyTorch, FAISS

> 🚧 Project under active development.
